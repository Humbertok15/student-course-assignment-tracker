# Cache Performance Analysis in C

## Project Description

Cache Performance Analysis in C is a web-based application that compares the performance of linked lists and dynamic arrays using large datasets of student records.

The project demonstrates how memory allocation, cache locality, and data structures influence application performance.

## Objectives

- Compare linked lists and dynamic arrays.
- Analyze execution time and memory usage.
- Demonstrate spatial locality and cache performance.
- Visualize benchmarking results.
